# v2ray Dikec Edition — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 240×240 yuvarlak ekranlı MU5358 saat için, güç tüketimi birinci öncelik olan, kendi reposunda yaşayan bir v2ray istemcisi (`com.kaandikec.u30prov2ray`).

**Architecture:** Yeni repo, yeni paket, yeni uygulama iskeleti. Kanıtlanmış protokol katmanları (`fmt/`, `core/`, `service/`, `dto/`, `util/`) v2rayNG fork'undan taşınır ve budanır; telefon UI'ı, ayar ekranları ve tüm arka plan makinesi gelmez. Kompakt yuvarlak ekran seti (bu projede yazılıp gerçek cihazda doğrulanmış) taşınır. Güç kazancı yeni kod yazmaktan değil, **kaldırmaktan** gelir: WorkManager'ın tamamı, 3 saniyelik bildirim döngüsü, ping/hız/sayaç.

**Tech Stack:** Kotlin 2.4.0, Jetpack Compose + Material3, Gradle Kotlin DSL, MMKV, Gson, OkHttp, yamalı `libv2ray.aar` (Xray-core, `allowInsecure` geri getirilmiş).

**Spec:** `docs/superpowers/specs/2026-08-02-u30pro-v2ray-design.md`

**Kaynak fork:** `/Users/kaandikec/Desktop/v2rayNG` — dal `feat/compact-round-screen`. Bu plan boyunca "FORK" bu yolu ifade eder. Fork **salt okunur**; hiçbir task fork'u değiştirmez.

## Global Constraints

- `applicationId` = `com.kaandikec.u30prov2ray`; Kotlin paket kökü `com.kaandikec.u30prov2ray`
- Uygulama adı (`R.string.app_name`) = **v2ray Dikec Edition**
- Lisans **GPL-3.0** — taşınan kod v2rayNG'den (GPL-3.0) geliyor; `LICENSE` ve kaynak atıfı zorunlu
- `minSdk 24`, `targetSdk 37`, `compileSdk 37` — taşınan kodun SDK varsayımlarıyla uyumlu
- **WorkManager bağımlılığı EKLENMEYECEK** (`work.runtime.ktx`, `work.multiprocess`)
- **CameraX ve zxing bağımlılıkları EKLENMEYECEK** (QR tarama kapsam dışı)
- **`reorderable` EKLENMEYECEK**
- Periyodik iş, tekrar eden coroutine döngüsü, `PeriodicWorkRequest` **hiç olmayacak**; bildirim sabit
- Tek ABI hedefi `arm64-v8a`; diğer ABI'ler için split üretilmez
- 58MB'lık `libv2ray.aar` **repoya commit edilmez** (`.gitignore`)
- Cihaz: `adb connect 192.168.0.1:55555` (port değişebilir; bağlanamazsan 5555 dene)
- Emülatör alternatifi: `round240` AVD — 240×240 @160dpi, `notround`, gerçek cihazın niteleyicileriyle birebir

```kotlin
package com.kaandikec.u30prov2ray.handler

import android.app.NotificationChannel
import android.app.NotificationManager as AndroidNotificationManager
import android.app.PendingIntent
import android.app.Service
import android.content.Context
import android.content.Intent
import androidx.core.app.NotificationCompat
import com.kaandikec.u30prov2ray.R
import com.kaandikec.u30prov2ray.ui.MainActivity

/**
 * Foreground-service notification.
 *
 * Deliberately static. v2rayNG runs a coroutine that queries core traffic stats over IPC
 * and rewrites this notification every 3 seconds — roughly 1200 wakeups an hour while
 * connected. On a watch that is the single largest avoidable battery cost, so there is no
 * loop here at all: the notification is posted once when the service starts and is not
 * touched again until it stops.
 */
object NotificationManager {

    private const val CHANNEL_ID = "u30prov2ray"
    const val NOTIFICATION_ID = 1

    fun buildNotification(service: Service, profileName: String?): android.app.Notification {
        createChannel(service)

        val pending = PendingIntent.getActivity(
            service,
            0,
            Intent(service, MainActivity::class.java),
            PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT,
        )

        return NotificationCompat.Builder(service, CHANNEL_ID)
            .setSmallIcon(R.mipmap.ic_launcher)
            .setContentTitle(service.getString(R.string.app_name))
            .setContentText(profileName ?: "")
            .setContentIntent(pending)
            .setOngoing(true)
            .setOnlyAlertOnce(true)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build()
    }

    private fun createChannel(context: Context) {
        val manager = context.getSystemService(Context.NOTIFICATION_SERVICE)
                as AndroidNotificationManager
        val channel = NotificationChannel(
            CHANNEL_ID,
            context.getString(R.string.app_name),
            AndroidNotificationManager.IMPORTANCE_LOW,
        )
        manager.createNotificationChannel(channel)
    }
}
```

```kotlin
package com.kaandikec.u30prov2ray.ui

import android.app.Application
import androidx.lifecycle.AndroidViewModel
import androidx.lifecycle.viewModelScope
import com.kaandikec.u30prov2ray.core.CoreServiceManager
import com.kaandikec.u30prov2ray.dto.entities.ProfileItem
import com.kaandikec.u30prov2ray.handler.MmkvManager
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch

/**
 * Holds exactly the state the three compact screens need.
 *
 * There is no polling here on purpose: no periodic refresh, no ping timer, no traffic
 * counter. State changes only when the user acts or the service reports a transition.
 */
class MainViewModel(app: Application) : AndroidViewModel(app) {

    private val _profiles = MutableStateFlow<List<Pair<String, ProfileItem>>>(emptyList())
    val profiles: StateFlow<List<Pair<String, ProfileItem>>> = _profiles.asStateFlow()

    private val _selectedGuid = MutableStateFlow(MmkvManager.getSelectServer())
    val selectedGuid: StateFlow<String?> = _selectedGuid.asStateFlow()

    private val _isRunning = MutableStateFlow(false)
    val isRunning: StateFlow<Boolean> = _isRunning.asStateFlow()

    fun refresh() {
        viewModelScope.launch {
            _profiles.value = MmkvManager.decodeServerList("")
                .mapNotNull { guid -> MmkvManager.decodeServerConfig(guid)?.let { guid to it } }
            _selectedGuid.value = MmkvManager.getSelectServer()
            _isRunning.value = CoreServiceManager.isRunning()
        }
    }

    fun select(guid: String) {
        MmkvManager.setSelectServer(guid)
        _selectedGuid.value = guid
    }

    fun setRunning(running: Boolean) {
        _isRunning.value = running
    }
}
```

```kotlin
package com.kaandikec.u30prov2ray.importer

import android.os.Environment
import java.io.File

/**
 * Reads profile URLs from a fixed file on shared storage.
 *
 * The Magisk module drops the file there and grants the storage permission; without the
 * module the user must grant "All files access" by hand.
 */
object ConfigFileImporter {

    private const val DIR_NAME = "v2ray"
    private val FILE_NAMES = listOf("config.txt", "configs.txt")

    /** Default location: /sdcard/v2ray */
    fun defaultDir(): File = File(Environment.getExternalStorageDirectory(), DIR_NAME)

    /** First existing candidate in [dir], preferring config.txt. Null if neither exists. */
    fun locate(dir: File): File? =
        FILE_NAMES.map { File(dir, it) }.firstOrNull { it.isFile }

    /** Non-blank, non-comment lines, trimmed. */
    fun readLines(file: File): List<String> =
        file.readLines()
            .map { it.trim() }
            .filter { it.isNotEmpty() && !it.startsWith("#") }
}
```
